# AeroTk 🚀

> A lightweight, ultra-fast, and modern UI library for Python. Built to outpace and outshine CustomTkinter with zero external dependencies.

[![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**AeroTk** is designed for developers who want gorgeous, modern, and smooth desktop user interfaces in Python without bloating their projects with heavy dependencies or clunky frameworks. Powered purely by Python's built-in `tkinter` under the hood, but completely reimagined with smooth anti-aliased geometry, rounded corners, and native dark/light theme support.

---

## ✨ Features

* **Zero External Dependencies:** Runs purely on Python core libraries. No heavy installations or complex toolchains required.
* **Modern Aesthetics:** Built-in rounded rectangles, custom hover effects, and hand-crafted color palettes.
* **Lightweight & Fast:** Drops the heavy footprint of other wrapper libraries for blazing-fast performance.
* **Seamless Theming:** Instant switching between Dark and Light modes out of the box.
